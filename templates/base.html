Panduan & FAQ Aplikasi
Bagaimana Cara Kerja Prediksi Dosis CL-80?

Aplikasi memprediksi Dosis CL-80 pada kondisi operasional tanpa bahan kimia penunjang. Input model terdiri dari kondisi inlet/outlet, discharge, tiga lag observasi sebelumnya, dan tiga fitur turunan.

Langkah Operasional Alur Machine Learning:
  1. Unggah Dataset: Masuk ke menu Dataset untuk mengunggah file data operasional harian (.csv / .xlsx).
  2. Prapemrosesan Data: Masuk ke menu Preprocessing untuk melakukan cleaning (TSS > 2000, dosis 0), penanganan missing value/duplikat, pembatasan outlier winsorize, pembentukan lagging memory (T1, T2, T3), dan chronological train-test split (80:20).
  3. Pelatihan Model: Masuk ke menu Training Model untuk melatih Linear Regression, XGBoost, dan LightGBM serentak untuk mendapakan model terbaik.
  4. Evaluasi Model: Tinjau performa akurasi metrik RMSE/R² di menu Evaluasi Model.
  5. Prediksi Dosis: Gunakan menu Prediksi Dosis CL-80 untuk menghitung set-point dosing pompa secara instan atau batch.
Mengapa Terdapat Kolom T1, T2, T3?

Kolom T1, T2, T3 merupakan dosis CL-80 pada satu, dua, dan tiga observasi sebelumnya. Interval tidak diasumsikan tepat per jam kecuali interval timestamp telah divalidasi.

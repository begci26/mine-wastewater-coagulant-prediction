Tujuan Halaman

Halaman ini digunakan untuk mengunggah dataset penelitian, memvalidasi struktur parameter kualitas air, memeriksa statistik ringkasan deskriptif, serta mempersiapkan dataset untuk proses prapemrosesan data.

Penjelasan Ilmiah Data Kualitas Air Tambang

Optimasi proses koagulasi menuntut dataset dengan kualitas penulisan tinggi. Air limbah tambang mengandung partikel tersuspensi halus (TSS) dan kontaminan terlarut seperti Besi (Fe) dan Mangan (Mn) yang memiliki sifat hubungan korelasional non-linier kompleks dengan dosis penetral koagulan. Visualisasi statistik dasar dan tipe data membantu memetakan pola sebaran awal data operasional di lapangan secara presisi sebelum diaplikasikan pada model machine learning regresi.

Panduan Memverifikasi Dataset
  1. Gunakan panel **Drag & Drop** di bawah untuk menyeret file CSV atau XLSX dataset atau klik tombol cari untuk memilih berkas.
  2. Sistem secara otomatis memverifikasi ketersediaan target kolom wajib `Dosis CL-80 (ppm)` beserta validitas format.
  3. Amati **Informasi Metadata Dataset** untuk memeriksa ukuran file, baris, dan duplikasi baris.
  4. Tinjau pratinjau **10 Data Pertama** dan **10 Data Terakhir** menggunakan navigasi DataTables yang interaktif.
  5. Periksa tipe data, jumlah nilai kosong, dan nilai unik pada tabel informasi tipe data.
  6. Pelajari nilai rata-rata, kuartil (Q1, Q2/Median, Q3), deviasi standar, dan rentang min-maks pada tabel **Statistik Deskriptif**.
  7. Lanjutkan ke menu **Prapemrosesan Data** di sidebar kiri setelah data dinyatakan terverifikasi.

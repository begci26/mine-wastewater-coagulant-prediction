Tujuan Dashboard

Dashboard menyajikan ringkasan dataset aktif tersanitasi, visualisasi kualitas air, status model regresi, serta metrik aktual dari konfigurasi parameter model yang tetap.

Penjelasan Proses Penelitian

Penelitian tesis ini bertujuan mengoptimalkan penentuan dosis koagulan CL-80 pada IPAL tambang batubara. Pemanfaatan algoritma regresi (Linear, XGBoost, LightGBM) dengan memadukan data lagging memory target (T1, T2, T3) bertujuan mengurangi pemakaian bahan kimia berlebih serta menjaga kualitas air sesuai ambang regulasi lingkungan.

Panduan Siklus Alur Aplikasi
1. Upload: Unggah file CSV/XLSX kualitas air harian di menu Dataset.
2. Preprocessing: Bersihkan outlier dan hitung fitur lagging di menu Preprocessing.
3. Training: Latih model regresi secara otomatis di menu Training Model.
4. Prediksi: Uji parameter baru untuk set-point dosing pompa di menu Prediksi.

Panel Informasi Penelitian Tesis
Judul Penelitian : Optimasi Prediksi Dosis Koagulan Dalam Pengolahan Air Limbah Tambang Menggunakan Algoritma Regresi
Tujuan Penelitian : Menentukan dosis koagulan CL-80 secara optimal untuk meminimalisasi konsumsi bahan kimia dengan tingkat akurasi tinggi dan mencegah pencemaran lingkungan.
Target Prediksi : Dosis koagulan CL-80 (ppm)
Dataset yang Digunakan : Dataset aktif tersanitasi untuk kondisi operasional CL-80 tanpa bahan kimia penunjang.
Algoritma Regresi : Linear Regression (SPSS baseline), XGBoost Regressor, LightGBM Regressor.
Variabel/Fitur Model : 11 fitur: kondisi inlet/outlet, inlet discharge, tiga lag observasi CL-80, Efisiensi_TSS, Delta_pH, dan Beban_TSS.
